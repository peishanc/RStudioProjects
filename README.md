**Project Description:**
This project implements a simple linear regression analysis using base R functions to explore the relationship between the number of beers consumed and blood alcohol content (BAC). We developed our own regression functions in `SimpleRegression.R` and used the dataset `bac.csv` for analysis. The project includes a reproducible Quarto report (`Analysis.qmd`) summarizing the regression results, diagnostics, and interpretations. A general description of the repository content is detailed below:


- `bac.csv`: Dataset containing blood alcohol content and number of beers consumed for 16 students.
- `SimpleRegression.R`: R script implementing simple linear regression and helper functions.
- 'Analysis.qmd`: Quarto document containing code, output, and narrative for the analysis.
- `Analysis.html`: Rendered HTML report generated from the Quarto document.
